# Лабораторная работа №7 - Консольное приложение

## 1. Цель работы

Объединить знания из ЛР1-ЛР6 в единое работающее CLI-приложение. Реализованы: интерактивное меню, обработка ошибок, сохранение/загрузка данных в JSON, сортировка, фильтрация, типизация.

## 2. Структура проекта
src/lab07/
├── main.py # Точка входа, загрузка/сохранение
├── cli.py # Интерфейс: меню, ввод, вывод
├── app.py # Бизнес-логика, операции над коллекцией
├── exceptions.py # Собственные исключения
├── storage.py # JSON сохранение/загрузка
└── README.md # Документация


**Назначение файлов:**
- `main.py` - запуск, автозагрузка при старте, автосохранение при выходе
- `cli.py` - только ввод/вывод, меню, форматированный вывод
- `app.py` - бизнес-логика, работа с коллекцией, фильтрация, сортировка
- `exceptions.py` - `DuplicateItemError`, `ItemNotFoundError`
- `storage.py` - сериализация/десериализация продуктов в JSON

## 3. Описание CLI

### Пункты меню
1. Добавить товар (обычный / питание / цифровой)
2. Список всех товаров (таблица)
3. Найти по ID
4. Найти по имени
5. Удалить товар (с подтверждением)
6. Фильтрация (доступные / со скидкой / цена ≤)
7. Сортировка (5 стратегий: имя, цена ↑↓, конечная цена, остаток)
8. Применить скидку
9. Статистика
0. Выход

### Обработка ошибок
- Неверный пункт меню → сообщение, повтор запроса
- Ввод строки вместо числа → `ValueError`, повтор запроса
- Дубликат ID → `DuplicateItemError`
- Поиск несуществующего ID → `ItemNotFoundError`

### Сохранение/загрузка (оценка 5)
- При запуске автоматическая загрузка из `data.json`
- При выходе (0 или Ctrl+C) автоматическое сохранение
